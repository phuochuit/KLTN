Layout & DPI review

Ngưỡng wide đề xuất: 1180 logical pixels client; cần hiệu chỉnh theo font và native measurement.

1366×768 tại 150% chỉ còn khoảng 911×512 logical pixels trước taskbar/chrome. Vì vậy minimum height hiện hành không tự chứng minh dùng được ở mọi scale.

Task 2 phải kiểm client working area, focus, text wrap, dialog scrolling và monitor changes; không dùng HTML này làm bằng chứng DPI WinForms.

Thứ tự đọc / Tab

Context → biển số → người → evidence/actions → preview/confirm → utilities. Ảnh có nút mở/zoom; tile có Enter/Space hoặc native list tương đương.

Không hotkey gây commit

Không global Enter/F-key mở barrier hoặc xác nhận thu. Dialog trả focus về control gọi; lỗi tại field liên quan.
