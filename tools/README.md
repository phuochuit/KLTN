# Công cụ của dự án

`tools/` chứa source hỗ trợ, không chứa bản cài Maven hoặc output. Launcher/runner nằm ở `scripts/`; toolchain tải về nằm ở `.cache/toolchains/`.

- [Thesis tools](thesis/README.md): các generator/chuyển đổi DOCX lịch sử; không authoritative cho nghiệp vụ.
- Công cụ khảo sát local chưa đủ installation/provenance để xuất bản hoặc coi là dependency của ứng dụng.
- [Workspace policy](../docs/architecture/workspace-layout.md).
