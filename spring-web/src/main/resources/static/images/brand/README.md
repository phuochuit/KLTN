# LumiPark Login assets — visual draft

Active Login assets: `lumipark-icon.svg` (original gateway P: gate post, canopy and negative-space entrance lane), `favicon.svg` (same geometry), and `parking-environment.svg` (original architectural vector with skyline, canopy, glazing, barrier, rear-three-quarter SUV, planted trees and road arrow pointing toward the gate). Created for this project; no copied third-party paths, external links, embedded raster images or operational data. The live wordmark uses the locally licensed Be Vietnam Pro font; see `static/css/fonts/be-vietnam-pro/README.md`.

Visual direction is inspired by three user-supplied Login references, not an exact reproduction. The vector parking concept is **not** AI-generated or a photorealistic 3D replacement; final hero artwork and visual acceptance remain open. No external image-generation service was called.

`lumipark-full.svg`, `lumipark-lockup.svg`, `lumipark-reversed.svg` and `parking-scene.svg` belong to the previous teal/lime proposal; `parking-architecture.svg` is the earlier isolated blue isometric concept. All are retained, unused by the new Login. They are not an approved complete identity kit for the new P. Do not apply the Login assets to other screens without approval.

Canonical visual specification: `design-system/kltn/pages/login.md` at repository root.
