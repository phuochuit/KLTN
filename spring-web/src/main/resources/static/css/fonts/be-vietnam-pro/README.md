# Be Vietnam Pro

Latin and Vietnamese WOFF2, normal weights 400/500/600/700, from `@fontsource/be-vietnam-pro@5.2.8` via jsDelivr. Original family: https://github.com/google/fonts/tree/main/ofl/bevietnampro

SIL Open Font License 1.1 is included as `OFL.txt`. Font files are unmodified and served locally under the existing public `/css/**` asset path; no browser font/CDN requests. Login-only CSS uses `font-display: swap`.
